# Project Instructions

- All PHP code must remain compatible with PHP 5.3 through PHP 8.x. Do not use syntax, language features, or APIs that are unavailable in PHP 5.3 or incompatible with PHP 8.x.
- Use `snake_case` for variables, functions, methods, and properties, and `PascalCase` for classes.
- Keep the project version at `0.1.0` for now. Do not increment or otherwise change it unless the user explicitly requests a version change.
